# 🏗️ Portfolio Architecture

My portfolio itself is built as a production-oriented **Next.js application** with a data-driven architecture.

```text
                    ┌──────────────────────┐
                    │      Browser         │
                    │   Next.js / React    │
                    └──────────┬───────────┘
                               │
                               ▼
                    ┌──────────────────────┐
                    │   Interactive UI     │
                    │     page.tsx         │
                    └──────────┬───────────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                ▼                ▼
       ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
       │ Portfolio   │ │ Animation   │ │ Components  │
       │    Data     │ │   Hooks     │ │  & Sections │
       └─────────────┘ └─────────────┘ └─────────────┘
                               │
                               ▼
                    ┌──────────────────────┐
                    │    Server Action     │
                    └──────────┬───────────┘
                               │
                               ▼
                    ┌──────────────────────┐
                    │       Resend         │
                    │    Email Delivery    │
                    └──────────────────────┘
```

The application separates portfolio content from presentation through a centralized data layer, while server-side form handling keeps email credentials away from the client.
